# Kaggle-Challenge-Project
Mushroom Challenge 
- The Mushroom Classification challenge asks us to build a model to safetely predict a mushroom's edibility to potentially save lives.

  Overview
  - The Mushroom Classification Challenge is to predict whether or not a mushroom is going to be edible (labeled in the dataset as e) or poisonous (labeled as p) based on different characteristics found in mushrooms.
  - The approach was to use certain features found in the dataset that could lead us to creating a model that can accurately predict edible or poisonous. Then, classification models will be chosen such as Random Forest for its ability to handle large datasets such as this and its ability for high accuracy, and Naive Bayes for dealing with categorical values and making predictions. 
- Summary of performance: As expected, the Random Forest Model was able to more accurately predict edible and poisonous compared to Naive Bayes with a score of: 99% (and 98% after removing some features that may have been influencing the predictions),
